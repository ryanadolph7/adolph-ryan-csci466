Ryan Adolph, Programming Assignment 5 - Fun Fact Cloud API

To run this code: 

You will need to upload app.py onto an AWS server.

Once uploaded, you simply need to run the curl command on your local terminal.

For Client informaiton: 
you will use the curl <Server Public IP>/info 

For random fun facts: 
you will use curl --header "amount: {amount of fun facts}" <Server Public IP>/fact
